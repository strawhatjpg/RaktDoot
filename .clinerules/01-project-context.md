# Project context

- Product: **RaktDoot**, a WhatsApp-first blood access coordination platform for India.
- Hackathon: Cline AI Builder Hackathon Round 2. 8-hour build. Deliverables: public GitHub repo + README, PPT, demo video (mandatory), social post.
- Primary channel: WhatsApp Cloud API. Secondary: installable mobile web app (PWA). Staff use a responsive dashboard.
- Read `docs/ROADMAP.md`, `docs/PIPELINES.md` and `docs/USER_ROLES.md` before starting any feature.
- In scope: multilingual AI intake, blood-centre-first discovery, verified requests, smart matching, wave outreach, closed-loop tracking, manual location updates, in-chat consent, reminders, demand forecasting, Cline SDK Coordinator Copilot, non-monetary recognition.
- Out of scope: prescription/slip reading, native mobile apps, live location tracking, token rewards (feature-flagged off), clinical compatibility advice.
